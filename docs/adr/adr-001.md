# ADR-001: Build the habit tracker as a web app with SQLite

   Status: accepted

   ## Context
   Solo practice project, small scope, need something simple to run.

   ## Decision
   Use a web UI with SQLite as the single data store, behind a repository interface.

   ## Consequences
   Easy for anyone to clone and run with zero setup. Swapping to a bigger database later only touches the Data tier.
